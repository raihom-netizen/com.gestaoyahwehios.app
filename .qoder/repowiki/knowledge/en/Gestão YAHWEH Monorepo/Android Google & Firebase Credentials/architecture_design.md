This is a credential-and-configuration leaf module with no source code. It holds three types of Google/Firebase artifacts: `google-services.json` (app-level config copied into `flutter_app\android\app\`), `client_secret_*.json` (OAuth client secret for server-side flows), and `*-firebase-adminsdk-*.json` (service-account JSON granting admin access to Firestore/Auth). Two README files document how these files are used — `README_CREDENCIAIS.txt` explains copying/syncing via `scripts\sync_android_google_services.ps1`, SHA-1/SHA-256 registration in Firebase Console, and Digital Asset Links; `README_PLAY_FOTOS_VIDEOS.md` records Play Store media-permission policy and the AAB build script `scripts\build_android_play_store_aab.ps1`. The `.gitignore` explicitly excludes admin SDK and client-secret files from version control, while `google-services.json` is intentionally committed because it contains only a limited API key scoped to the package name.
