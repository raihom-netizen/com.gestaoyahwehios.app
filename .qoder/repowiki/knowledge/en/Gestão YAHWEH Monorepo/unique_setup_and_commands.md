Local dev: run Firebase emulators via `firebase.json` (Firestore :8080, Storage :9199, UI :4000). Production deploy on Windows via `DEPLOY_WINDOWS.bat`, on Mac/Linux via `bash DEPLOY_MAC_LINUX.sh`. iOS releases are triggered manually in Codemagic using the repository's `codemagic.yaml` (no auto-trigger); secrets are grouped under `appstore_credentials` and optionally `firebase_ipa_upload`.
