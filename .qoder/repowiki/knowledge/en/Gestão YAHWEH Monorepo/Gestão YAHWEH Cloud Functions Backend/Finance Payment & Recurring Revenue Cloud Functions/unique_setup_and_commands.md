Each function is deployed as a separate Firebase Function; region is set to `us-central1` and memory/timeout configured via `runWith({ timeoutSeconds: 300, memory: "512MB" })`. Mercado Pago credentials are stored per-tenant under `igrejas/{tid}/private/mp_credentials` and must be configured before any donation flow works. The MP webhook URL is derived from `GCLOUD_PROJECT`/`GCP_PROJECT` env vars to build `https://us-central1-${projectId}.cloudfunctions.net/mpWebhook`.
