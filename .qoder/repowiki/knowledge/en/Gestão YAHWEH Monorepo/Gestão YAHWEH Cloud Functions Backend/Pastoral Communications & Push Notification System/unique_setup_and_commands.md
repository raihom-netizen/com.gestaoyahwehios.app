All functions are deployed as part of the Firebase Functions project in `functions/`; region is fixed to `us-central1` via `.region("us-central1")`. The brand logo must be served at `{PUBLIC_WEB_BASE_URL}/brand/gestao_yahweh_mark.png` from the associated Firebase Hosting site. Chat-specific Android channel IDs referenced in `chatDelivery.androidChannelId` must be declared in the Flutter app's `ChurchChatAlertNotificationService`.
