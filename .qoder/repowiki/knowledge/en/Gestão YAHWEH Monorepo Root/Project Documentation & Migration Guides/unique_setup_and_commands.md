Migration guides in `docs/migracoes/` are designed to be applied to sibling apps (Controle Total, Moova Super Premium) using Cursor prompts from `PROMPT_APLICAR_EM_OUTROS_APPS.md`; iOS hardening requires specific `Info.plist` keys, `Runner.entitlements` entries, and `PrivacyInfo.xcprivacy` registration. Web deployment uses three PowerShell scripts under `scripts/deploy_web_hosting*.ps1` selecting different renderers.
