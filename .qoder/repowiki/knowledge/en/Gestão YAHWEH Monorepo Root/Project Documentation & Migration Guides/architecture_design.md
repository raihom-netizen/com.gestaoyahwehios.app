The docs/ directory is a flat collection of Markdown reference documents organized by purpose rather than code modules. Three structural clusters emerge: (1) `backup_wisdomapp/sources/lib/` holds mirrored source trees from the WISDOMAPP reference project (`screens/`, `services/`, `utils/`) plus two manifest files describing performance references; (2) `migracoes/README.md` acts as an index for cross-app replication guides covering iOS App Store Guidelines 3.1.x/3.2.2(iv), Express Login, and donation flows, with per-app applicability matrices; (3) the root contains architecture blueprints (`ARCHITECTURE_*`, `PADRAO_MESTRE_WISDOMAPP_YAHWEH_TOTAL.md`), production readiness checklists (`CHECKLIST_*.md`, `FASE_FINAL_QA.md`), Firebase observability patterns, multi-platform standardization notes, and audit/reports (`RELATORIO_*`, `tenants-collection-audit-report.md`). Documents cross-reference each other via relative links and serve as the single source of truth for performance targets, cache-first templates, and strict publish ordering.
