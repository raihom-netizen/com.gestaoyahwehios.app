This is a credential-and-configuration leaf module with no executable code — it holds the signed artifacts and human-readable setup guides consumed by the CI pipeline. Subdirectories split concerns: `IOS/apn/` contains the APNs `.p8` key and APNs setup notes; `IOS/bootstrap_signing_output/` holds artifacts produced by the Codemagic bootstrap workflow (`.p12`, `.der`, `.pem`) used to seed secrets; `widget/` holds the Widget extension's provisioning profile and its own README. The root of `IOS/` mixes operational docs (`CODEMAGIC_SIGNING_FIX.md`, `APP_STORE_3_1_1_ORGANIZATION_SIGNUP.md`, `ATUALIZAR_APOS_NOVO_CERTIFICADO.txt`) with raw credentials (`.p8`, `.cer`, `.mobileprovision`, `.p12`). Dependency direction is one-way: the Flutter iOS targets (`ios/Runner`, `ios/GestaoYahwehWidget`) consume these artifacts via Codemagic environment variables; this module does not import any project code.
