Three independent Firebase Functions v1 entry points under `functions/src/`, each exporting one or more callable/exported helpers:
- `publicChurchSlugIndex.ts` exposes `syncPublicChurchSlugKey`/`syncPublicChurchSlugIndexForChurch` plus two functions: an `onWrite` Firestore trigger on `igrejas/{tenantId}` (`onIgrejaWritePublicSlugIndex`) and a restricted `https.onCall` backfill (`backfillPublicChurchSlugIndex`) gated to a hardcoded admin email. Both write normalized slug documents into `public_church_slugs/{key}` with schema versioning.
- `publicSignupEmail.ts` is a pure utility module exporting `trySendPublicSignupConfirmationEmail`; it reads configuration through `firebase-functions/params.defineString` (`SENDGRID_API_KEY`, `SENDGRID_FROM_EMAIL`, `SENDGRID_FROM_NAME`, `PUBLIC_WEB_BASE_URL`) and calls the SendGrid v3 API directly via `fetch`. It depends on `notificationBranding.gestaoBrandLogoUrl` for the logo asset.
- `publicSiteMediaPrefetch.ts` provides reusable extractors (`collectHttpPhotoUrls`, `collectHostedVideoUrl`, `collectVideoThumbUrl`, `enrichPostMedia`) plus a batch recomputation function `recomputePublicSiteMediaPrefetch` that reads `_performance_cache/public_feed`, resolves Firebase Storage paths to signed download URLs, and writes enriched data plus a `prefetchUrls` list capped at `MAX_PREFETCH_URLS=96`. Its only exported Function is `warmPublicSiteFeedCache`, an `https.onCall` that delegates to `churchPerformancePack.refreshPublicFeedCacheForTenant` and `panelPublicSiteCache.mirrorPublicSitePanelCache` via dynamic `import()`.

Dependency direction is one-way: these modules import shared utilities from `./panelMediaPrefetch`, `./notificationBranding`, `./churchPerformancePack`, and `./panelPublicSiteCache`, but are never imported by them — they sit at the edge of the system as public-facing functions.
