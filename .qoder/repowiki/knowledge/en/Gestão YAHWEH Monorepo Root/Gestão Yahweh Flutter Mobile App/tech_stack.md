Flutter SDK >=3.12.0 with Firebase suite (Auth, Firestore, Storage, Functions, Messaging, Analytics, Crashlytics, Performance, Remote Config), Hive for local storage, TDLib (libtdjson.a static library) for optional Telegram chat integration, Google ML Kit for OCR/face detection, FFmpeg for video processing, and native platform integrations via Kotlin (Android) and Swift (iOS). Build system uses Gradle (Kotlin DSL) for Android, Xcode/Pods for iOS, and CMake for desktop targets.
