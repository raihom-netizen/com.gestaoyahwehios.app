TDLib setup requires running `dart run tool/setup_tdlib.dart --ios-only` to fetch libtdjson.a binaries before iOS builds; production pubspec excludes flutter_libtdjson dependency due to CI archive failures. Web deployment uses PowerShell/Batch scripts in `scripts/deploy_web_agora.*`. Codemagic CI configuration is in `codemagic.yaml`. Version bumping follows the pattern in `CONFIG_VERSAO_APP.md` with marketing version aligned to `lib/app_version.dart`.
