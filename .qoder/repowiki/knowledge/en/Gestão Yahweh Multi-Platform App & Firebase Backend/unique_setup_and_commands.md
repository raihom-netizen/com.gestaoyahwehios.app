TDLib requires running `dart run tool/setup_tdlib.dart` locally and in CI before `pod install` (`--ios-only` flag for iOS). Secrets are loaded from `.env` / `.env.example` via `flutter_dotenv` — never committed. iOS signing uses CodeMagic with P12 profiles and ASC API keys managed through `scripts/codemagic_ios_*.sh` and `*.py`. Deployment is driven by PowerShell scripts under `scripts/` (e.g., `deploy_completo.ps1`, `build_android_aab.ps1`, `deploy_web_hosting.ps1`) rather than direct CLI commands.
